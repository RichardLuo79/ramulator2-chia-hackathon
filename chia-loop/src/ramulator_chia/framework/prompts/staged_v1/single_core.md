# Single-core stage

This is the single-core stage, rounds 1–10. Improve a broadly useful model
across the named training cohort. Examine both workload-level errors and
request-level failures within otherwise accurate workloads.

Use training diagnostics to distinguish model limitations from closed-loop
timing effects and observation-coverage limitations. Synthetic and replay
results are diagnostic evidence, not replacements for full-window ChampSim
measurements.

End with one candidate ready for final evaluation.
